# Prototype demonstration guide

## Suggested script

1. Open the homepage. Note the announcement that listings are demo data.
2. Employer path: Hire Skilled Workers → Submit Manpower Request → complete four steps → copy the `REQ-` reference → Admin demo → Employer inquiries.
3. Job seeker path: Explore Job Opportunities → filter → open a vacancy → submit name, phone, and email → confirmation with a reference number. There is no applicant dashboard.
4. Staff path: Admin → Applications → open the new record and contact details. Create/publish a vacancy and confirm it on `/jobs`.
5. Settings → Reset demo data to restore the seed.

## What is simulated

- Login/registration
- Form submissions and file names
- Interviews (no invitations)
- Document review (file name only)
- CMS copy on the homepage announcement/hero
- CSV exports of non-sensitive demo fields

## What you must not do in a demo

- Upload passports or national IDs
- Present demo vacancies as live jobs
- Claim emails were sent
